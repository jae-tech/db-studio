# AI DB Studio

Windows 우선 로컬 Electron 데이터베이스 작업 공간. 기본 화면은 한국어이며 [한글화 범위와 용어](docs/LOCALIZATION.md)를 참고하세요. Phase 2의 MSSQL 연결 관리·Explorer·승인 기반 SELECT 실행·취소·결과/이력을 구현했습니다. 실제 개발 MSSQL 서버의 메타데이터·SELECT 실행과 Electron 검토·승인·그리드·이력 검증이 통과했습니다. 로컬 전용 DB에서 대량 결과 제한·잠금 대기 취소/timeout·SELECT-only 계정 검증도 통과했으며, 신뢰 인증서의 운영 TLS 수용은 남아 있습니다. Phase 3의 Codex 구독 CLI 텍스트 대화·스트림·세션 재개도 구현했습니다. Phase 4의 opt-in 연결 범위 MCP/메타데이터 캐시/스키마 예산/SELECT 제안·오류 분석도 구현했습니다. 실제 DB→Main→MCP→공식 Codex→UI 제안과 별도 승인 실행까지 검증했습니다. AI는 Codex(ChatGPT 구독)와 GitHub Copilot(Copilot 구독) 공식 CLI를 쓰며, AI 패널에서 모델 이름을 지정하고 패널을 접을 수 있습니다. Claude·Gemini는 약관상 구독 방식으로 쓸 수 없어 제외했습니다(ADR-032). 서버 실행계획은 미지원입니다. Phase 5의 개발 opt-in 제한 UPDATE/DELETE 미리보기·승인·트랜잭션은 실제 로컬 SQL Server와 Electron UI에서 commit/rollback/잠금/권한·트리거 거부/자동 rollback·종료 정리를 검증했습니다. 운영 연결도 SSMS처럼 서버 인증서 신뢰를 체크해 접속할 수 있고, 제한 쓰기는 연결별로 직접 허용할 때만 켜지며 실제 권한은 로그인 계정의 DB 역할을 따릅니다(ADR-031).

```powershell
pnpm install
pnpm dev
```

Node >=22.12, pnpm 11.5.2. 개발용 Vite 외 별도 API 서버가 필요 없습니다. Electron userData의 preferences.db에는 SQL 탭/테마/패널 폭을, database.db에는 OS 암호화 연결 정보와 최근100건 이력을 저장합니다. SQL 탭과 이력은 평문이므로 자격 증명을 SQL에 입력하지 마세요.

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm test:e2e
pnpm test:db
pnpm format:check
```

새 연결에서 SQL Server 인증 정보를 저장한 뒤 연결을 누르세요. 테이블을 펼쳐 스키마를 확인하고 SQL을 작성하고 Ctrl+Enter를 누르면 커서가 있는 문장(또는 선택 영역)이 별도 승인 없이 바로 실행됩니다. Alt+X는 편집기의 모든 문장을 차례로 실행하고 문장마다 결과 탭(1, 2, …)을 만듭니다. 문장은 `;` 또는 빈 줄로 나뉩니다. 쿼리 실행은 제한된 SELECT 문법만 허용합니다. 쓰기·CTE·서브쿼리·뷰·저장 프로시저·다중 문장은 차단합니다. [MSSQL 사용/테스트 안내](docs/MSSQL_TESTING.md)를 참고하세요. 개발 전용 쓰기는 연결을 끊고 개발용 제한 쓰기 허용를 직접 켜야 하며, UPDATE/DELETE 미리보기 → 대상 검토 → 트랜잭션에 적용 — COMMIT 아님 → 별도 DB 이름 확인/변경 확정(COMMIT) 순서입니다. PK+rowversion/100행 상한이 있고, 미확정30초 후 rollback합니다. [제한 쓰기 안내와 실DB 검증 범위](docs/WRITE_TESTING.md)을 먼저 읽으세요.

AI 패널의 **CLI 확인**으로 공식 Codex CLI 0.165.0과 ChatGPT 로그인을 확인한 뒤 메시지를 보내세요. API 키/다른 버전/인증 확인 실패는 거부합니다. 연결된 DB가 있으면 메시지 전송 시 **현재 DB의 테이블·컬럼 구조를 자동 공유**합니다. 공유 체크박스는 없습니다. 행 데이터·엑셀 셀·SQL 탭·접속 비밀번호는 자동 전송하지 않습니다. 연결 선택만으로 AI를 호출하지 않으며 DB 연결이 없으면 텍스트 대화로 동작합니다. 응답 중지, 새 대화를 지원합니다. [CLI 정책과 검증 안내](docs/AGENT_TESTING.md)를 참고하세요. AI가 만든 조회(SELECT)는 묻지 않고 새 SQL 탭에서 바로 실행해 결과를 보여줍니다(결과 행은 AI로 보내지 않습니다). AI가 만든 INSERT/UPDATE/DELETE는 바뀔 행 미리보기를 먼저 보여주고 "실행할까요?"에 [실행]을 눌렀을 때만 적용·COMMIT합니다(개발용 제한 쓰기 연결 전용). AI는 `SELECT *` 대신 필요한 열을 나열합니다. [MCP 사용/한도/잔여 검증](docs/MCP_TESTING.md)을 참고하세요.

자주 쓰는 SQL은 SQL 탭 위 입력칸에 `이름, 별칭`을 적고 현재 SQL 저장 → 이후 이름이나 별칭으로 불러와 실행합니다(현재 연결/DB 전용, 정확히 일치할 때만). **AI 대화창에서도 `매출`, `매출 조회해줘`, `/조회 매출`로 저장 쿼리를 호출할 수 있습니다.** 현재 SQL 탭에 불러와 SELECT를 검증·실행하고 결과 그리드에 표시합니다. CLI 로그인이나 메타데이터 공유 없이 로컬 처리하며 SQL/결과를 AI로 전송하지 않습니다. 모호한 이름·다른 DB는 거부하며 쓰기는 기존 미리보기·승인 절차가 필요합니다. 이름으로 저장하지 않은 일반 질문은 기존처럼 CLI 상태 확인 후 전송합니다.

왼쪽 탐색기의 **연결 목록** 옆 폴더 버튼으로 연결 그룹(예: 운영, 개발)을 만들고, 각 연결 카드의 그룹 선택으로 옮깁니다. 그룹과 섹션은 제목을 눌러 접고, 탐색기 전체는 제목의 접기 버튼이나 왼쪽 맨 위 버튼으로 접고 펼칩니다.

Ctrl+N: SQL 탭 추가. Ctrl+Enter: 현재 문장 실행. Alt+X: 전체 실행. 패널 경계 드래그: 폭·편집기 높이 조절. `pnpm test:db`와 live Electron 테스트는 명시한 테스트 환경변수가 없으면 skip합니다. `pnpm pack`은 설치 전 앱 디렉터리, `pnpm dist:win`은 Windows 설치 파일 생성 명령이며 배포 검증은 Phase 6 범위입니다.

결과 헤더의 **CSV**/**XLSX** 버튼은 그 결과를 만든 SQL을 다시 실행해 화면 상한과 상관없이 전체 행(최대 1,048,575행)을 파일로 저장합니다. 저장 위치는 대화상자에서 고르며 실행 중에는 쿼리 취소로 멈출 수 있습니다. CSV는 UTF-8(BOM)이고 셀 값을 그대로 쓰므로 `=`로 시작하는 값은 Excel에서 수식으로 열릴 수 있습니다. 신뢰할 수 없는 데이터는 XLSX를 권장합니다. SQL 탭 제목은 두 번 클릭하거나 F2를 눌러 바꿀 수 있습니다.

결과 하단의 **다음 페이지**를 누르면 필요한 데이터가 자동으로 조회됩니다. 이미 읽은 페이지는 추가 조회하지 않습니다. 건수·페이지의 `+`는 아직 더 조회할 데이터가 있다는 뜻이며, 전체 크기를 알기 전에는 마지막 페이지로 바로 이동할 수 없습니다. 화면 정렬·필터는 불러온 행에 적용됩니다.

SQL은 기본적으로 불필요한 `[]` 없이 앞쪽 쉼표·대문자 키워드·JOIN ON 정렬로 생성합니다. 툴바 **SQL 정리**(Alt+Shift+F)로 현재 SQL을 정리하고, 옆 **SQL 포맷 설정**에서 스타일을 미리 보고 저장할 수 있습니다. 필요한 식별자 인용은 유지하며 정리만으로 SQL을 실행하지 않습니다. [SQL 포맷 사용법](docs/SQL_FORMATTING.md)을 참고하세요.

실제 FK가 없어도 탐색기에서 테이블을 클릭해 열리는 상세 화면 아래에서 연결 테이블만 고르면 같은 이름 열이 자동으로 짝지어져 바로 저장할 수 있습니다(업무명은 생략 가능). 왼쪽 **가상 관계**에서도 업무명·별칭과 테이블 연결 열을 저장할 수 있습니다. 예를 들어 `부가서비스 밴` 관계를 등록하고 AI에 같은 이름으로 질문하면 JOIN 작성에 활용합니다. 실제 DB 제약/데이터는 바꾸지 않으며 관계 유형은 유일성을 보장하지 않습니다. [가상 관계 사용법과 제한](docs/VIRTUAL_RELATIONSHIPS.md)을 참고하세요.
